# 煤岩力学术语账本

在写作前按作者材料删减本表，并把选定形式锁定为全文唯一标准。术语一致性优先于同义替换。变量、下标和单位以作者的试验定义为准。

## 材料与结构

| 中文规范形式 | English canonical form | 使用边界 |
|---|---|---|
| 煤体 / 煤样 | coal / coal specimen | `coal mass` 指原位或工程尺度煤体；`coal specimen` 指试样。 |
| 岩体 / 岩样 | rock mass / rock specimen | 不用 `rock body` 代替试样。 |
| 煤岩组合体 | coal–rock composite | 有明确煤、岩组分和界面的组合试样。若强调分层装配且原文一直用 assemblage，可锁定为 `coal–rock assemblage`，但全文只选一种。 |
| 层状岩体 | layered rock mass | 与 `stratified rock mass` 二选一；本语料优先 `layered`。 |
| 胶结破碎煤复合体 | cemented broken-coal composite (CBC) | 首次定义 CBC，之后使用缩写。 |
| 煤矸石 | coal gangue | 破碎状态写 `broken coal gangue`。 |
| 层理面 | bedding plane | 天然沉积构造面。 |
| 界面 | interface | 煤–岩或异质材料接触面；界面过渡区为 `interfacial transition zone (ITZ)`。 |
| 裂隙 | fissure | 既有、预制或尺度较大的离散结构面，强调几何位置、倾角和岩桥。 |
| 裂纹 | crack | 加载过程中萌生、扩展、贯通的破坏迹线。 |
| 断裂 | fracture | 过程或总体破裂行为；作为名词指破裂面时要说明尺度。 |
| 节理 | joint | 地质结构面；除非来源明确定义，不与 fissure 互换。 |
| 预制裂隙 / 预制裂纹 | prefabricated fissure / prefabricated crack | 根据制样方式和作者定义选择。切槽不自动等同天然裂隙。 |
| 岩桥 | rock bridge / ligament | 连接两裂隙之间的完整材料。若用 `ligament`，首次说明其指岩桥区。 |

## 应力路径与力学参数

| 中文规范形式 | English canonical form | 说明 |
|---|---|---|
| 单轴压缩 | uniaxial compression | 单轴抗压强度为 `uniaxial compressive strength (UCS)`。 |
| 常规三轴压缩 | conventional triaxial compression | 通常满足两个侧向主应力相等；不得简称为 true triaxial。 |
| 真三轴压缩 | true triaxial compression | 三个主应力可独立控制。 |
| 三轴加载 / 三轴卸载 | triaxial loading / triaxial unloading | 说明卸载哪一方向及其他方向是恒定、加载还是同步变化。 |
| 循环加载–卸载 | cyclic loading–unloading | 写明应力水平、循环次数、上下限和速率。 |
| 非对称加载 | asymmetric loading | 给出两侧载荷或应力比，不只写“非均匀”。 |
| 最大 / 中间 / 最小主应力 | maximum / intermediate / minimum principal stress | 分别记为 $\sigma_1$、$\sigma_2$、$\sigma_3$；若试验使用 x/y/z 方向，先建立映射。 |
| 围压 | confining pressure (CP) | 仅在物理含义确为围压时使用；首次可定义 CP。 |
| 偏应力 | deviatoric stress | 必须说明采用的差值或不变量定义。 |
| 卸载路径 | unloading path / unloading stress path | 路径要写明顺序，如 $\sigma_x$–$\sigma_y$–$\sigma_z$。 |
| 卸载速率 | unloading rate | 用 MPa/s 等单位；不要与加载速率混写。 |
| 应力水平 | stress level | 指归一化水平时给出相对峰值强度或目标应力的定义。 |
| 峰值应力 / 峰值强度 | peak stress / peak strength | 试验曲线读数多用 peak stress；跨试样能力比较可用 peak strength，全文统一。 |
| 峰值应变 | peak strain | 明确轴向、横向或体积应变。 |
| 弹性模量 | elastic modulus / Young's modulus | 依据计算区间选择；若无严格线弹性拟合，不擅自写 Young's modulus。 |
| 泊松比 | Poisson's ratio | 写明计算区间。 |
| 长期强度 | long-term strength | 适用于蠕变；不能用峰值强度替代。 |
| 裂纹起裂应力 | crack-initiation stress | 与裂纹损伤应力 `crack-damage stress` 分开。 |
| 承载能力 | load-bearing capacity | 避免泛用；应由峰值应力、残余强度或变形能力支撑。 |

## 变形、裂纹与破坏

| 中文规范形式 | English canonical form | 说明 |
|---|---|---|
| 压密阶段 | crack-closure/compaction stage | 数值模型若未包含初始孔裂隙，不应声称复现该阶段。 |
| 弹性阶段 | elastic stage | 只在曲线或循环响应支持近似弹性时使用。 |
| 稳定裂纹扩展阶段 | stable crack-growth stage | 与 unstable crack-growth stage 对应。 |
| 裂纹萌生 | crack initiation | 首次出现。 |
| 裂纹扩展 | crack propagation / growth | 选一个主要形式；描述路径常用 propagation。 |
| 裂纹贯通 | crack coalescence | 多裂纹汇合形成宏观破裂路径。 |
| 张拉裂纹 / 剪切裂纹 | tensile crack / shear crack | 裂纹类型；与 tensile/shear failure 的宏观破坏模式区分。 |
| 翼裂纹 | wing crack | 从裂隙尖端产生的张拉型分支裂纹。 |
| 张剪复合破坏 | mixed tensile–shear failure | 若有主导类型，写 `shear-dominated mixed failure` 等。 |
| 宏观裂纹 / 微裂纹 | macrocrack / microcrack | 尺度判定来自观测或模型，不按重要性命名。 |
| 损伤变量 | damage variable | 必须给出基于耗散能、AE、模量或其他定义。 |
| 破坏模式 | failure mode | 与 `failure mechanism` 区分：前者是表征，后者是因果解释。 |

## 能量项

| 中文规范形式 | English canonical form | 说明 |
|---|---|---|
| 输入能 / 输入应变能密度 | input energy / input strain-energy density | 总外功进入试样的能量；密度形式需写单位。 |
| 弹性应变能 / 弹性应变能密度 | elastic strain energy / elastic strain-energy density | 可恢复储能。 |
| 耗散能 / 耗散应变能密度 | dissipated energy / dissipated strain-energy density | 与不可逆变形、摩擦、裂纹演化等相关；并非等同于裂纹能。 |
| 动能 | kinetic energy | 常用于抛射、冲击或离散元颗粒运动。 |
| 断裂能 / 比断裂能 | fracture energy / specific fracture energy | 定义与单位要跟随试验或模型。 |
| 能量积聚 / 储存 | energy accumulation / energy storage | `accumulation` 强调过程，`storage capacity` 强调能力。 |
| 能量耗散 | energy dissipation | 不可逆消耗过程。 |
| 能量释放 | energy release | 储能在卸载或破坏阶段释放；不要与耗散互换。 |
| 能量转化 | energy conversion | 必须指明从哪一项转化到哪一项。 |
| 能量演化 | energy evolution | 可作总称，但结果句应落到具体能量分量。 |

## 监测与表征

| 中文规范形式 | English canonical form | 缩写与注意事项 |
|---|---|---|
| 声发射 | acoustic emission | 首次写 `acoustic emission (AE)`。 |
| AE事件 / AE源 | AE event / AE source | event 是触发记录，source 是定位或机制意义上的源。 |
| AE计数 | AE counts | 与振铃计数设备定义一致；若原设备输出 ring-down counts，则全文用 `AE ring-down counts`。 |
| 累积AE计数 | cumulative AE counts | 不写 `accumulative`，除非期刊沿用。 |
| AE绝对能量 | AE absolute energy | 与普通 AE energy 区分并给出单位。 |
| $b$值 | AE $b$-value | 说明窗口、事件数和计算公式；下降通常对应较大尺度事件增多，但不自动等于失稳。 |
| $S$值 | AE $S$-value | 必须给出来源和定义，不能假定读者知道。 |
| RA–AF分析 | RA–AF analysis | 首次展开 RA、AF 的计算含义；用于裂纹类型判别时说明阈值或准则。 |
| 矩张量反演 | moment-tensor inversion | 用于数值 AE 事件定位/类型识别时说明矩张量来源。 |
| 数字图像相关 | digital image correlation (DIC) | 说明二维或三维、采样频率、感兴趣区域和应变分量。 |
| X射线计算机断层扫描 | X-ray computed tomography (CT) | 说明原位/加载后、分辨率和分割标准。 |
| 扫描电子显微镜 | scanning electron microscopy (SEM) | 说明观测尺度及其与宏观结论的连接。 |

## 数值方法

| 中文规范形式 | English canonical form | 说明 |
|---|---|---|
| 离散元法 | discrete element method (DEM) | PFC 是 DEM 实现之一。 |
| 颗粒流程序 | Particle Flow Code (PFC) | 用 `PFC2D` 或 `PFC3D` 指明维度。 |
| 有限–离散元法 | finite–discrete element method (FDEM) | 与 FEM、DEM 分开。 |
| 颗粒/晶粒模型 | grain-based model (GBM) | 给出晶粒几何生成和材料赋值方法。 |
| 离散裂隙网络 | discrete fracture network (DFN) | 说明几何统计量、尺度阈值和等效原则。 |
| 平行黏结模型 | parallel-bond model (PBM) | 说明其代表的胶结行为和破坏准则。 |
| 光滑节理模型 | smooth-joint model (SJM) | 用于层理/节理面时说明方向与参数。 |
| 细观参数 | microparameters / mesoscopic parameters | 选择一个形式；PFC 文献常用 microparameters。 |
| 参数标定 | parameter calibration | 说明目标曲线/指标和误差。 |
| 模型验证 | model validation | 必须使用未仅被用于标定的可观察量，或明确是“与试验结果对比”。 |

## 工程术语

| 中文规范形式 | English canonical form | 说明 |
|---|---|---|
| 冲击地压 / 岩爆 | rockburst | 若研究煤样冲击破坏而非现场事件，可用 `burst failure`，避免全部译为 rockburst。 |
| 抛射破坏 | ejection failure | 说明碎块速度、动能或可见抛射证据。 |
| 动力灾害 | dynamic hazard | 具体化为 rockburst、coal and gas outburst 等。 |
| 长壁综放 | longwall top-coal caving (LTCC) | 首次定义 LTCC。 |
| 放煤回收率 | top-coal recovery rate | 与总采出率分开。 |
| 含矸率 | gangue content | 说明质量或数量口径。 |
| 采放比 | mining-to-drawing ratio (MDR) | 给出比值定义和方向。 |
| 配位数 | coordination number | 颗粒接触网络指标。 |
| 孔隙率 / 空隙率 | porosity / voidage | 固体材料孔隙结构多用 porosity；散体填充状态常用 voidage。 |
| 力链 | force chain | 可写强力链/弱力链，但需给出判定方法。 |
| 二次破碎 | re-breaking / secondary breakage | 对压实后再次破碎的散体煤矸石优先 `re-breaking`。 |

## 缩写纪律

1. 标题通常不用缩写；摘要首次出现时写全称加括号缩写。
2. 同一缩写不得表示两个概念。`CP`、`PB`、`DC` 等短缩写尤其要谨慎。
3. $\sigma_1$、$\sigma_2$、$\sigma_3$ 的排序关系与试验轴向映射只定义一次，图表和正文必须一致。
4. 单位使用 SI 形式：数值与单位间留空格，如 `20 MPa`、`0.10 MPa/s`、`100 mm`。
5. 角度统一写作 `30°`，范围写作 `0°–90°`；不要混用字母 `o` 代替角度符号。
