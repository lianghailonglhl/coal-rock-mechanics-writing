# 论证逻辑与章节骨架

本指南总结 30 篇煤岩力学论文反复出现的有效论证动作。它约束“怎样把证据连起来”，不提供可移植的研究结论。

## 1. 先判定研究类型

| 类型 | 核心问题 | 推荐证据链 |
|---|---|---|
| 应力路径/速率效应 | 路径、速率或围压如何改变响应 | 应力–应变 → 强度/变形 → 能量分配 → 裂纹/AE → 失稳模式 |
| 结构缺陷效应 | 裂隙、层理、孔洞、界面或粒径如何控制破坏 | 几何变量 → 应力集中/力链 → 起裂与贯通 → 宏观破坏 → 参数敏感性 |
| 监测与前兆 | 哪些信号能识别阶段或临近失稳 | 阶段划分 → AE/DIC/CT 指标 → 与应力/能量同步 → 阈值/前兆 → 适用边界 |
| 数值模型/方法 | 模型能否复现并解释行为 | 方程/接触模型 → 参数标定 → 独立验证 → 参数研究 → 机制解释 → 限制 |
| 试验–模拟耦合 | 宏观现象如何由细观机制产生 | 试验事实 → 模型复现 → 细观场/裂纹证据 → 机制闭环 |
| 工程参数优化 | 哪组参数在给定工程条件下更合理 | 工程约束 → 理论/模型方案 → 指标比较 → 推荐区间 → 现场或相邻矿井验证 |

一篇论文可以含多个类型，但主贡献只能有一个。标题、摘要末句和结论最后一项应围绕同一主贡献。

## 2. 标题

标题优先表达 `研究对象 + 主变量/工况 + 核心响应或方法`：

- `Effect of [stress path/rate/geometry] on [mechanical/energy/fracture response] of [material] under [condition]`
- `[Failure/crack/energy] characteristics of [material] under [loading path]`
- `[Method] investigation of [mechanism] in [material/system]`
- 中文：`[工况/变量]下[对象]的[响应]与[机制/特征]`

不要在标题中并列所有监测手段；只有方法本身构成创新时才写入标题。

## 3. 摘要：六步压缩链

按一个连续逻辑完成，不把摘要写成章节目录。

1. **工程背景**：一句说明实际应力场、结构缺陷或工程问题。
2. **具体空白**：指出在某工况、尺度或证据耦合上尚未解决的问题。
3. **研究动作**：对象、变量、主要方法和比较组。
4. **关键结果**：优先给 2–4 个量化趋势、排序、阈值或转变。
5. **机制解释**：用一条完整因果链解释最重要结果；证据不足时用 `suggests/indicates`。
6. **工程意义**：说明结果服务于哪类预测、设计或参数选择，并给适用条件。

中文骨架：

> [工程过程]使[对象]经历[具体工况]，但[明确空白]仍不清楚。为此，本文采用[方法组合]，研究[自变量]对[响应变量]的影响。结果表明：[量化趋势1]；[趋势/排序2]；[阶段或阈值3]。结合[细观/监测证据]可知，[受限机制判断]。研究结果可为[具体工程决策]提供依据。

英文骨架：

> [Engineering process] exposes [material/system] to [specific condition], yet [precise gap] remains unclear. Here, [method package] was used to examine how [independent variable] affects [responses]. The results show that [quantified finding 1], whereas [comparison or transition]. [Mesoscale/monitoring evidence] indicates that [bounded mechanism]. These findings inform [specific decision] within [tested condition/range].

摘要禁忌：只写“结果良好/影响显著”；把文献综述放入摘要；结果无数字却声称“定量揭示”；末句泛写“具有重要理论意义”。

## 4. 引言：漏斗式七段动作

不强求七个自然段，但逻辑顺序应完整。

1. **工程场景与风险**：深部开采、巷道开挖、卸荷、扰动、充填或放煤等。
2. **物理问题**：把工程场景转换成可研究变量，如真三轴路径、卸载速率、裂隙方位、层理角、非对称载荷。
3. **已知规律**：按问题而非按作者罗列文献，归纳现有证据。
4. **方法进展**：说明 AE、DIC、CT、DEM/PFC/FDEM 等能提供哪一层证据。
5. **精确空白**：使用 `对象 + 条件 + 尚缺证据/机制`，避免“鲜有研究”后无解释。
6. **本研究动作**：写对象、变量、路径、观测指标和验证方式。
7. **贡献与边界**：说明新增的是规律、方法、机制还是工程参数，并限制在试验范围内。

高质量空白句必须回答三个问题：

- 哪类对象或工况没有被覆盖？
- 缺的是趋势、跨尺度证据、机制还是验证？
- 这一缺口为何影响工程判断？

弱：`Few studies have investigated coal under unloading.`

强：`Existing studies mainly address monotonic or conventional triaxial loading; how the intermediate-principal-stress path regulates energy redistribution and crack-mode transition during true-triaxial unloading remains unresolved.`

综述段落使用“问题簇”：

- 先给共同结论；
- 再区分方法或边界；
- 最后指出冲突或空缺；
- 不连续使用多句 `X et al. studied...`。

## 5. 方法：可复现的决策顺序

方法章节不是设备清单。应按“为什么这样设计”组织：

1. 材料来源、结构特征和试样几何；
2. 自变量、对照组和重复；
3. 初始应力状态与完整加载/卸载路径；
4. 监测系统、采样设置和同步方式；
5. 指标计算、阶段划分和阈值定义；
6. 数值接触模型、边界条件、参数标定和验证；
7. 统计或不确定性处理。

每个关键设置回答“该设置如何对应研究问题”。如果模型不包含压密阶段、二维几何、真实随机裂隙或时间效应，应在方法或局限中提前说明。

## 6. 结果：结论先行的四句单元

推荐段落单元：

1. **局部结论**：变量如何影响指标，注明单调、非单调或阶段性。
2. **证据**：数字、排序、差值、斜率、峰值、阈值、置信区间或重复一致性。
3. **图表定位**：引用图中具体曲线、分区或时段，而不是“见图”。
4. **局部解读**：仅解释当前结果，完整机制留给 Discussion。

常用结果问题：

- 随变量增加，响应是单调、U形、倒U形、阶跃、波动还是先稳后突变？
- 哪个角度/速率/围压/应力水平对应极值？
- 不同指标是否同步？若不同步，时间先后本身是否构成机制证据？
- 宏观强度、能量分量、AE 参数和裂纹模式是否相互印证？
- 观测到的是统计差异、趋势还是个例？

不要把“图中存在”写成“证明机制”。

## 7. 讨论：从趋势到机制的五级链

机制段优先使用以下链条，并只保留有证据的节点：

`边界/加载条件变化 → 应力重分布或力链调整 → 局部应力集中/界面约束 → 裂纹萌生、扩展与贯通 → 能量储存/耗散/释放变化 → 宏观破坏模式或工程响应`

每个机制判断要标记证据来源：

- 应力–应变或能量曲线：宏观响应；
- AE：事件时序、能级或裂纹类型的间接证据；
- DIC：表面局部应变与裂纹路径；
- CT：内部裂纹几何和体积；
- PFC/DEM/FDEM：模型内的细观机制，不能无条件等同真实材料；
- 现场数据：工程相关性，但控制变量通常弱于实验。

Discussion 建议包含：

1. 解释最重要的非单调、阈值或转变；
2. 与既有研究比较一致与不一致；
3. 说明方法为何能支持该解释；
4. 明确替代解释；
5. 给出适用范围和工程含义。

## 8. 结论：每项回答一个问题

常见的 3–5 项结构：

1. **力学响应**：强度、变形或长期强度的主规律；
2. **能量/监测响应**：能量分配、AE/DIC/CT 的阶段规律；
3. **裂纹与破坏机制**：起裂—扩展—贯通和主导破坏类型；
4. **模型/方法贡献**：新模型、标定/验证或指标有效性；
5. **工程建议与边界**：具体参数、监测信号或设计启示及测试范围。

结论项写成 `发现 + 证据 + 限定`，而不是再讲研究过程。不能引入正文未出现的新数字或新机制。

## 9. 四类常用论证闭环

### 速率或围压效应

`变量增大 → 峰值/模量/应变变化 → 储能或耗散比例变化 → AE 活动或裂纹模式变化 → 渐进/脆性/抛射破坏转变`

### 裂隙与层理耦合

`几何方位 → 裂隙尖端与界面应力集中 → 翼裂纹或层间滑移 → 岩桥贯通 → 强度极值与破坏模式`

### 监测前兆

`应力阶段 → AE/DIC 指标时序 → 多参数同步或错位 → 临界前兆 → 误报边界`

### 工程参数优化

`工程约束 → 参数组 → 破碎/流动/回收指标 → 机制解释 → 推荐区间 → 现场或邻近案例验证`

这些闭环是提问清单，不是结果模板；缺证据的环节必须省略或标为假设。
